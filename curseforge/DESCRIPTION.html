Volumetric fog makes some zones look like soup. There is a console setting that turns it off, and this is a button for it.

Click the button on your minimap: the fog is gone. Click it again: it is back. That is the whole addon.

What it does, exactly

It sets volumeFog to 0, which is what /console volumeFog 0 does — without you having to remember the name of the setting or type it again after the console settings are wiped.

The button

  • The sign is lit when the fog is off and greyed when it is back, so it shows what it has done rather than what it will do.
  • Drag it around the minimap; where you leave it is remembered.
  • Change the setting in the graphics options instead and the button notices, so it never shows the opposite of the truth.

Commands

CommandWhat it does
/fogbegone, /ffbgthe same as clicking
/ffbg hideput the button away; the command still works
/ffbg showbring it back
/ffbg resetput it back where it started

Two things it refuses to do

It will not change the setting while you are in combat, where it is protected on some builds, and says so instead of failing quietly. On a client that has no volumeFog setting it tells you that, rather than taking the missing setting for "fog is on" and then blaming the write that fails.

No libraries

One Lua file and one icon. LibDBIcon would be four files and a dependency for a single button, and this addon is a single button.

Works on Retail, on Classic Era, and on World of Warcraft: Forever. Source: github.com/Ironship/ForeverFogBeGone.
